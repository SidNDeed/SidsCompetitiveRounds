# Sid's Competitive Rounds

A ranked competitive mod for **vanilla ROUNDS v1.1.2 ONLY** by Landfall. Built for the Competitive Rounds Discord community.

> **⚠️ IMPORTANT: This mod is designed exclusively for vanilla ROUNDS v1.1.2 (the "Default Public Version" on Steam). It is NOT compatible with older versions, beta branches, or other mods. The mod will automatically disable itself if it detects an incompatible game version or other BepInEx plugins installed.**

## Features

- **Glicko-2 Rating System** — Skill-based matchmaking rating that adjusts after each ranked series
- **Best-of-3 Ranked Series** — Ranked matches are played as BO3 series with Elo changes on completion
- **Ranked Matchmaking Queue** — Server-side queue with Elo-based tiered matching and mutual ready-up
- **In-Game Leaderboard** — Sortable leaderboard with player detail panel, head-to-head records, recent form, and top cards
- **Card Stats** — Per-card pick counts and win rates, filterable by Ranked/Casual/All
- **Match History** — Full match history with BO3 series grouping, card picks, opponent cards, XP earned
- **XP & Leveling** — Earn XP from matches with bonuses for wins, ranked play, sweeps, and top-5 finishes
- **11 Achievements** — Including Untouchable, Pacifist, Immovable Object, The Comeback Kid, and more
- **Session Info** — Live opponent lifetime W/L record, session stats, per-opponent breakdown
- **Discord Integration** — Link your Discord account, get rank roles, series results posted to channel
- **HMAC-Signed Match Reports** — Anti-cheat match verification
- **FPS + Ping + Region** — Live connection info overlay

## Compatibility

- **Required**: ROUNDS v1.1.2 (Steam "Default Public Version", updated Dec 2, 2025)
- **Required**: BepInEx 5.4.22
- **NOT compatible** with any other BepInEx mods — this mod must be the only plugin installed
- **NOT compatible** with older ROUNDS versions or Steam beta branches

## How It Works

1. Install via r2modman or Thunderstore Mod Manager
2. Launch ROUNDS — the mod loads automatically
3. Click "SID'S COMPETITIVE ROUNDS" in the main menu
4. Enable Ranked to start tracking your matches
5. Use "Search Ranked" to find opponents through the matchmaking queue
6. Join our Discord for the full community experience: https://discord.gg/comp-rounds

## Controls

- **F5** — Toggle competitive overlay while in-game
- **ESC** — Close the competitive page
