# Frame-time survivors: state that survives the point boundary

Codex FRAME-TIME round 1 HIGH 2 and ruling FRAME-TIME-ROUND-R1-A1 part 2. This file lists every structure
of the seven components that a hook or tick writes, that is not reset at the point boundary, and that a
live path reads. It extends INVENTORY.md's nine iii rows and ZERO-STATE.md. It proposes no resets: each
row says what a frame-time calibration must hold steady before a point's live reads cost the same as in
any other point.

`tools/frametime/survivor_sweep.py` is the sweep. It is the source of the counts and of the field list in
every row, and it fails (exit 1) when this file disagrees with it:

    python -I -B tools/frametime/survivor_sweep.py             # SURVIVOR SWEEP PASS
    python -I -B tools/frametime/survivor_sweep.py --selftest  # SELFTEST PASS
    python -I -B tools/frametime/survivor_sweep.py --detail    # every survivor with its write and live-read sites

A structure found after this sweep is a sweep defect, not an addendum: fix the sweep, then the table.

## Method

1. **Sources.** The seven components and their files, as listed in the script's `COMPONENTS`:
   CombatEvidence (CombatEvidence.cs, CombatEvidenceCore.cs, CombatEvidencePerf.cs,
   CombatEvidenceWire.g.cs), SeatEvidence (SeatEvidence.cs, SeatEvidenceCore.cs), HitEvidence
   (HitEvidence.cs, HitEvidenceCore.cs), PointEvidence (the `PointEvidence` class slice of PoisonSync.cs, up
   to `PoisonPointBoundaryPatch`), IdentityClockEvidence (IdentityClockEvidence.cs, IdentityClockCore.cs),
   CardDrawEvidence (CardDrawEvidence.cs, CardDrawEvidenceCore.cs), PeerBuild (PeerBuild.cs,
   PeerBuildCore.cs).
2. **Exclusion of `#if SCR_FRAMETIME` code.** Comments and string literals are blanked first (interpolation
   holes stay code). The preprocessor is then evaluated with `SCR_FRAMETIME`,
   `SCR_CARD_EVIDENCE_TEST_DEALER` and `SCR_CARD_EVIDENCE_TEST_GATE` UNDEFINED (the release build): the
   `#if` branch is blanked and its `#else` kept; every other symbol keeps all branches. Blanked code is
   never parsed, so its fields are not declared and its writes and reads are not counted.
   The script prints the blanked line count per file (CardDrawEvidence.cs 125, CardDrawEvidenceCore.cs 0,
   CombatEvidence.cs 822, CombatEvidenceCore.cs 12, CombatEvidencePerf.cs 80, CombatEvidenceWire.g.cs 0,
   HitEvidence.cs 262, HitEvidenceCore.cs 11, IdentityClockCore.cs 22, IdentityClockEvidence.cs 235,
   PeerBuild.cs 108, PeerBuildCore.cs 0, PoisonSync.cs#PointEvidence 87, SeatEvidence.cs 349,
   SeatEvidenceCore.cs 28).
   CardDrawEvidenceTestDealer.cs is wholly under `SCR_CARD_EVIDENCE_TEST_DEALER` and is not a source.
3. **Fields declared.** A structural parse (types, members, field declarations; leading attributes
   stripped) gives each component's fields: every static field of every class declared in its files, plus
   every instance field of every class the component HOLDS, found by type closure from those static
   fields. Constants are not fields.
4. **Writes counted.** Only inside member bodies (declaration initialisers are construction): `=` stores,
   compound assignments, `++`/`--`, BCL collection mutators (Add, Clear, Remove and the like, only on a
   field typed as a BCL collection), `out`/`ref` arguments, Array.Copy/Clear/Fill/Reverse/Sort/Resize and
   Buffer.BlockCopy destinations, ternary-selected element writes, and writes through aliases (a call
   parameter or a reference-typed local bound to the field, followed to depth 3). Qualifiers are resolved
   by type (fields, parameters, typed and `var` locals, properties); a dotted occurrence whose qualifier has
   another known type is not counted.
5. **Classification of each written field.** CONSTRUCTION-ONLY: every write is in a constructor of its
   class. RESET AT THE POINT: a whole-value store, a `Clear()`, or an Array.Clear/Fill of it inside a
   point-boundary member (the members reached from the point start/end/reset roots in the script's
   `POINT_ROOTS`, stopping at game, room and quit boundaries). Otherwise SURVIVES.
6. **Read live.** A survivor is READ LIVE when a non-store access of it sits in a live member: one reached
   by the call graph from the live hooks and ticks of INVENTORY.md (`LIVE_ROOTS`), not past a combat-return
   gate (`LIVE_CUT`: the combat or in-room returns of the Tick and Step members) and not across a guarded
   edge (`GUARDED_EDGES`). Calls are resolved by type; an unknown capitalised receiver is an external type
   and resolves to nothing.
7. **Rows.** Every survivor read live is named, as `Class.Field`, in exactly one S row. The sweep fails on
   a survivor with no row, a row naming a field that is not a live survivor, a field in two rows, a declared
   line that declares none of the row's fields, a capacity `NAME = value (File.cs:line)` whose constant is
   not on that line or has another value, or any other number in the capacity column. The counts table must
   equal the sweep, including the number of rows per component.
8. **A3 kinds (gate_specs/a3.py; ruling FRAME-TIME-ROUND-R2).** Every S row has exactly one a3.py row, a 5-tuple
   (name, survivor id, kind, reason, proof), and the kind is DEFAULT-DENY. ZERO only with proof
   `sweep:no-live-write`, which the sweep re-derives on every run: no field of the row has a write site inside a
   live member before its cut. No row qualifies today (every former zero row has live writes), so all 21 are
   dependent. DRAINED only by its executed probe (`probe:a3drain`, FtA3.PointStart). DEPENDENT otherwise: the sweep
   lists each row's live reader members and fails when one lacks `FtA3.Read(FtA3.<row>)` (or `FtA3.ReadOnce`) in its
   FrameTime text (SCR_FRAMETIME defined), directly, through a FrameTime-only helper that does, or COVERED by its
   callers (the script's `COVERED`: TopInsert for CE_Top / CE_Ht, Median for IC_Clock, each checked: every live
   caller is a covering caller that counts the row), and when an FtA3.Read of a row sits anywhere but in that row's
   live readers. `--detail` lists the readers per row; `--selftest` removes one read site, plants one, declares a
   written row zero, and shows a write-free field passes the zero proof.
9. **Generated text.** The blanked-line counts of item 2, the counts table, and each row's declared, writers and
   live-readers columns and capacity lines are the sweep's own output (`--write-md` writes them; never by hand); the
   sweep fails when any of them differs from what it computes, and `--selftest` changes one count and one pin.

The nine existing rows of INVENTORY.md map to S01 (#1 Top), S02 (#2 Ht), S03 (#3 PingBin), S04 (#4 L-hat
cache), S05 (#5 Pos), S11 (#6 B5c), S19 (#7 HitWindow), S30 (#8 RpcNames) and S31 (#9 ClockBook cadence),
re-verified at the current lines. The Rh/Rf rings are S06.
