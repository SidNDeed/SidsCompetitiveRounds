== what a clean result means here ==
`rows rewritten now : 0` is the result this round expects and requires. The
manifest already held every fingerprint the live tree produces, so the tool
changed nothing -- which is the positive statement that the committed manifest
and the committed code agree at the tip. A non-zero count at this point would
mean the tree moved after the suites certified it, and the suites would have to
be re-run rather than the number explained away.

That `rows rewritten now : 0` IS a result, rather than the absence of one, had
to be settled this round rather than assumed. The evidence check that reads
this directory did not recognise the phrase at all, and so reddened this report
as though it carried nothing but prose -- reddening the one artifact that was
carrying exactly the result it exists to carry. The
pattern learned the artifact rather than the artifact learning the pattern: a
rule that refuses a legitimate result does not hold a line, it teaches the next
author to pad the file until the rule is satisfied, and the padding is what the
rule exists to catch. The widening carries its own proof -- a both-directions
block inside the check and the `evidence-result-pattern-forgets-the-repin`
mutation control, which drops the new token and reds.

`MOVED vs HEAD` is a different question and is NOT zero: it compares this
working copy against the manifest committed at HEAD, so it names the routes
this BRANCH changes. Two are expected and both are routes this round touched:

  main.submit_ffa_match        -- the refusal path re-derives its progress

A route that moved for a reason nobody can name is a finding, not a re-pin;
these two are named.
