A control here is a pair, never a single edit. The MUTATION breaks the property
and the paired test must go RED; the INERT twin changes the same site without
changing its meaning -- a comment, a reflow, a doubled space -- and the same
test must stay GREEN. Without the second half a red proves only that the test
noticed SOMETHING, which is not the same as noticing the thing (#391), and a
check that cannot fail is worse than no check at all (#342).

logs named above: everything below the marker is their exact bytes, and the
assembler refuses to write the file at all when a number in this narrative is
absent from them.

the run that produced it, and each is LF because the instrument that wrote it

== what the runner does, and what it refuses to do ==
It edits a file in place, runs ONE test, restores the file from a byte-exact
copy taken before anything ran, and repeats for the inert twin. Never
`git checkout --` and never `git restore`: both are forbidden on a tree
carrying uncommitted work (#290, #401), and this tree is carrying the round.
Before it runs anything it resolves every anchor in its target file and refuses
outright unless each resolves EXACTLY ONCE -- an anchor matching twice would
mutate two sites and an anchor matching zero times would mutate none, and both
look identical in a summary. At the end it compares the md5 of every file it
touched against the value taken before the first mutation, and says so per file.

That refusal did its job on this round's own work, before any of it ran. Round
13 replaced the suffix wildcards in the evidence-log negation with exact names,
and the round-12 control that mutates that block was anchored on two of the
patterns that no longer exist. The pre-check said so -- an anchor resolving
zero times -- and the control was RE-ANCHORED on two of the exact names that
replaced them rather than dropped. A control that is not re-run on the tree it
certifies is an assertion about a different tree.

== this round's new controls ==
Five in the runner, and a sixth in the new instrument above. Two answer the
HIGH at the level it was raised -- the disposition a refusal carrying
`settled_game` gives an entry, and the bound on how often that disposition can
be taken -- and three answer the three LOWs.

  recovery-resubmits-the-stale-number
      Takes the RE-SIGN out of the recovery step, so the entry goes back out
      carrying the number it was just refused for. The contract's arm table
      gives that refusal one disposition -- keep the entry, re-sign it once at
      the advertised number, submit -- and this is that rule with its middle
      clause removed. What reds is the acceptance leg of the walk, because the
      endpoint refuses the stale number again; the refusal is CAUGHT there and
      recorded rather than allowed to escape, so the assertion that names the
      fact is the assertion that runs. The inert twin is the same assignment
      with a doubled space.

  terminal-walk-redirects-a-second-time
      Answers EVERY settled-game refusal with a redirect, so the bound is not
      one. The contract says no seat can be refused for the same reason twice,
      because the number the second attempt carries came from the server; a
      client that redirected again would make that sentence describe a loop
      nobody wrote down. Under the mutation the third entry of the walk is
      re-signed a second time instead of being dropped, and the disposition
      assertion reds. The inert twin is a comment at the same site.

  evidence-log-negation-takes-a-suffix-wildcard
      Puts one exact capture name back to the producer-suffix pattern it
      replaced. That pattern is narrower than the blanket `*.log` and still
      admits every file shaped like a capture, under a round nothing here has

      the exact names: the same set, a different order, so what reds is what
      the block ADMITS.

  inventory-mislabels-an-inert-twin

      and GREEN are unaffected -- which is precisely why nothing else could

      twin was executed. The check derives the KIND from the runner's own

      The inert twin is a doubled space in the same sentence.

  repin-types-its-commit-trailer
      Makes the re-pin wrapper's trailer derivation return a constant instead

  contract-arm-consistency (in its own instrument, not the runner)

== the freeze guard, and the older method beside it ==
The guard answers one question: did the tree move while the suite pair ran? A
guard that answers "no" for an edit class it cannot see is worse than no guard,
because the report then carries UNCHANGED over a tree the run did not have. So
its control performs each edit class and requires the guard to NOTICE, performs
no edit at all and requires it to stay quiet, and runs the earlier
captured-once method over the same two mutations side by side. That second half
is the negative result that makes the finding concrete rather than argued.

== the citation pin ==
The contract states which revision of the client-lane method design its
realignment section was checked against; that document declares its own revision
on its first line. A citation is stale exactly when the two differ. The control
reds on a revision rolled back under the citation and stays green on a reword
beside it. It takes both paths as ARGUMENTS and names neither, because both live
under the gitignored scratch and a committed file may not send a reader to a
path this repository does not contain.

== the residual list's reach ==
A round's residual list is the one place it says what it did NOT close, and it
is read by somebody deliberately not reading the rest -- so it is the place a
summary sentence is most expensive to get wrong. `residual_rules.py` is the
rule: every item states its reach once in a pinned shape, the count under the
list is derived from those tags, and no other line in the section may state a
reach at all. `residual-reach-control.py` runs it against the real document --
passed as an ARGUMENT, for the same reason the citation pin takes its two --
with the superseded sentence put back as one mutation, a removed tag as a
second, and a reword beside a tag as the inert twin. The document is read and
never written; every edit is made to a copy in a temporary directory.

== the arm table's disposition, which is new ==
The HIGH this round closes was not a defect in any one sentence: both sentences
were written deliberately, in different passes, and each is defensible on its
own. What was missing is anything that reads them together. So the check is
four facts, read off the document rather than restated here -- the row's
disposition is REDIRECT, that disposition does not also say the entry is
dropped, the row states the once-per-entry bound, and the recovery section
re-signs the SAME parked entry at the advertised number. A document where the
last holds and the first does not is the finding itself, and that is the
mutation.
