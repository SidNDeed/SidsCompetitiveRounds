touches.

== what a clean result means here ==
`rows rewritten now : 0` is the result this round expects and requires. The
manifest already held every fingerprint the live tree produces, so the tool
changed nothing -- which is the positive statement that the committed manifest
and the committed code agree at the tip. A non-zero count at this point would
mean the tree moved after the suites certified it, and the suites would have to
be re-run rather than the number explained away.

That `rows rewritten now : 0` IS a result rather than the absence of one was
settled in round 8: the evidence check that reads this directory did not
recognise the phrase, and so reddened the one artifact carrying exactly the
result it exists to carry. The pattern learned the artifact rather than the
artifact learning the pattern, and because widening a pattern makes a check
easier to satisfy, the widening brought its own proof -- a both-directions
block inside the check and a mutation control that drops the new token.

`MOVED vs HEAD` is a different question and is NOT zero: it compares this
working copy against the manifest committed at git HEAD, so it names the routes
this BRANCH changes since that commit. One is expected, and it is the only
route this round touched:

                            completed repair

A route that moved for a reason nobody can name is a finding, not a re-pin;
this one is named.
